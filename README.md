# 猛人下载器

<p align="center"><img src="assets/app.png" width="160" alt="猛人下载器图标"></p>

一个可以解压使用的 Windows 视频下载小工具。粘贴链接，选择画质，下载到系统“下载”文件夹。

当前版本 **v0.5.0 正式版** 使用命令行窗口交互，支持 YouTube、B 站、抖音、QQ 音乐单曲，以及通过已登录原网站读取的小鹅通直播回放、微信视频号分享链接。完成后可在同一个窗口继续下载。

## 下载和使用

**[下载 Windows x64 正式版完整包](https://github.com/longpeng1413/mengren-downloader/releases/download/v0.5.0/mengren-downloader-0.5.0-windows-x64-full.zip)** · [最新发布](https://github.com/longpeng1413/mengren-downloader/releases/latest)

到 [v0.5.0 正式版](https://github.com/longpeng1413/mengren-downloader/releases/tag/v0.5.0) 下载 `mengren-downloader-0.5.0-windows-x64-full.zip`。

1. **完整解压**到普通文件夹，不要在压缩包内直接打开。
2. 双击 **猛人下载器.exe**。完整便携包已经包含并校验全部下载组件，解压后即可运行，无需另找或下载组件。
3. 粘贴视频链接。YouTube、B 站可以选择最高画质、1080P、720P 或 480P；小鹅通/视频号/抖音按网页提供的画质下载。
4. 等待视频、音频下载及合并，完成后到当前电脑的系统 **下载** 文件夹查看。
5. 窗口会再次提示粘贴链接：输入新链接继续下载，**不输入内容、直接回车就退出**。失败后也可换链接或重试；每个新任务重新选择画质。下载中按 **Ctrl+C** 只中止当前任务，窗口保留，可继续粘贴下一条链接。

YouTube、B 站选择的清晰度是上限：例如视频只有 720P，选 1080P 也会下载最佳的 720P。直接回车默认最高画质；竖屏上限按高度计算。

双击 **创建桌面快捷方式.cmd** 可创建带“猛”字图标的桌面入口。请保留整个软件文件夹，移动后需要重新创建快捷方式。

## 播放抓取与课程批量下载

在普通链接提示处输入 **抓取**，阅读影响后输入 **开启**；再到微信、小程序或网页播放有权限的视频。回到下载器输入 **列表**，直接输入数字（如 **1**）下载；**1-8**、**1,3,5** 或 **全部 / 全部下载 / 下载全部** 可顺序批量下载已抓取的视频。课程名优先从明确关联的媒体信息读取；未读到时暂不启动该队列，等自动名称补齐后再输入下载指令，或先输入 **命名 1 峰级线基础画法**。不会切换到容易混淆的自由名称输入框。抓取文件按“01. 课程名称.mp4”保存，无时间/地址摘要后缀；序号优先网站明确提供的课程序号，否则用本次列表编号（采集顺序），仅下载第13–17项也不会从1重编号。可用 **序号 1 13** 将列表编号1设为课程第13节；同名文件追加 `(2)`，不覆盖原文件。默认仍保存到系统下载文件夹。抓取操作处空回车退出并尝试恢复网络。详细操作见 [抓取使用说明](抓取使用说明.txt)。

开启时临时改动当前用户系统代理、信任本机生成的抓取证书；关闭时尝试恢复原代理并移除自己的证书信任。证书/密钥不随包迁移，每台电脑独立生成。只临时读取限定课程响应中的名称和媒体关联，不保存完整响应、请求正文或 Cookie/登录凭证，媒体地址和名称仅驻留本次内存；仅解读配置的课程和常见媒体域名，其他 HTTPS 域名以加密隧道转发。原网站证书校验仍保留。

2026-10-12，用户在笔记本微信小程序实际使用后确认当前版本可用、未发现新问题，按此反馈发布正式版。强制关闭窗口或断电恢复仍未完成实体测试。本地 HTTP/HTTPS、媒体下载及隔离代理恢复测试已完成。不保证所有小程序、受保护内容、独立音轨或带会话限制的媒体可下载。网络异常先退出抓取，再运行 **恢复网络.cmd**；中途其他软件改动代理时不会强行覆盖。新增模块使用 Windows .NET Framework 4.8，无 Go、npm 或 Python 依赖。

批量列表只包含本次实际抓取的媒体；可依次打开 8 节课程、开始播放后返回输入“全部”，无需逐个编号下载。如果网站课程列表同时提供多节课程的名称和可下载媒体地址，会自动列入列表；只提供当前课媒体时仍需逐节打开，不能保证仅打开专栏就发现全集。名称无法确认时只接受显式“命名 编号 名称”，不按响应顺序猜测课程名。

## 抖音和 B 站

**抖音**：粘贴 `https://www.douyin.com/video/...`、`https://v.douyin.com/...` 或包含链接的分享文案。软件打开专用 Edge，读取当前视频播放器提供的音视频；需要登录或验证时请在原网站完成，随后自动继续。当前不提供抖音清晰度档位，也不保证所有视频的播放器格式可读取。

**B 站**：支持 BV/AV 视频链接、手机网页链接、`b23.tv` 分享短链，以及 `?p=2` 等单个分 P。优先直接解析；失败时打开专用 Edge，从当前视频页面读取并合并音画。画质范围取决于平台和账号当前权限，选择“最高”不代表可取得付费或账号未获授权的画质；直接解析成功时不使用专用 Edge 的登录，因此大会员专属画质目前拿不到；不会自动下载全部分 P。

## QQ 音乐（v0.5.0 新增）

粘贴单曲链接（`y.qq.com/n/ryqq/songDetail/...`、新版 `ryqq_v2`、手机播放页）或 App 分享的 `c6.y.qq.com` 短链，也可粘贴包含链接的分享文案。先选读取方式：

- **用会员账号读取（默认）**：在下载专用 Edge 的 QQ 音乐网页正常登录（QQ/微信扫码），之后复用登录。软件在该网页内调用 QQ 音乐官方接口，登录由浏览器自动带上，软件不读取 Cookie；服务器按账号权限决定可下音质，会员可能取得无损 FLAC 或 320k MP3。
- **不登录快速读取**：不打开浏览器，免费歌曲最高 128k MP3；读取不到时自动改用专用 Edge。

读取后列出这首歌全部可下载的音质、文件大小和兼容提示，输入编号选择；**直接回车选最高的 MP3**（会员通常是 320k），因为 MP3 几乎所有手机都能放。给老人机、车载或旧 MP3 播放器下载时选 MP3；FLAC 无损和 M4A 在这类设备上常常不认。只下载所选音质，失败时不会自动换成其他格式。

文件保存为“歌名 - 歌手.flac/.mp3/.m4a”，写入歌名、歌手、专辑标签，并在旁边保存同名 `.lrc` 滚动歌词；同名追加 `(2)`，不覆盖。只下载账号可以完整播放的歌曲：试听片段（时长明显短于整首）会被拒绝，带加密密钥的格式直接跳过，不解密客户端加密文件，不使用第三方解析网站。QQ 音乐服务器对每条连接限速，软件用 4 条连接分段下载并逐段校验。暂不支持歌单、专辑和歌手批量下载。

## 小鹅通和微信视频号

**小鹅通**：粘贴店铺课程/回放链接或 `xet.tech`、`xetslk.com`、`xetlk.com` 分享短链。软件打开下载专用 Edge；第一次按原网站流程登录店铺，有访问密码时自行在网页输入。软件自动检查同店铺允许读取的回放接口，尝试可用线路并合并为 MP4。电脑课程页只显示“微信打开”等限制页面时，也会从同店铺已登录页面读取服务器允许的回放。小鹅通文件名保留课程标题及标题中的日期，不加中括号地址编号；同名追加 `(2)`。当前重点验证已结束的直播回放；普通录播课、正在直播的内容和所有商家定制页面不能保证。

**微信视频号**：粘贴 `https://weixin.qq.com/sph/...` 分享链接。软件在下载专用 Edge 中打开腾讯元宝；首次正常登录后，**只把这条分享链接发送给元宝的解析接口，不发送聊天消息**。再打开腾讯官方播放页，读取并下载 `finder.video.qq.com` 媒体，合并为 MP4。该路径依赖元宝及腾讯官方网页的当前行为，并不保证每条视频号都能解析。

登录由浏览器在原网站完成；软件不读出或转交 Cookie。专用浏览器的登录会话会保留在当前电脑，通常无需每个视频重新登录；退出登录、会话过期、换店铺或换电脑时可能需要再次登录。它与日常 Edge 分开，**不能直接继承你日常 Edge 的小鹅通登录**。不需要关闭或重启日常浏览器。

取得视频后会自动继续，无需反复点“重新读取”。小鹅通/视频号当前下载所提供的原始源，**不承诺可切换分辨率**；不会把低清晰度视频放大成高清。临时播放地址不保存在项目/日志中，公开包也不包含登录状态。

## 运行要求与范围

- Windows 10 / 11，64 位 Intel 或 AMD 电脑。
- 无需安装 Python、Node.js、剪藏插件或剪藏助手。需要 Windows 自带或已安装的 .NET Framework 4.8；抓取证书只作用于当前 Windows 用户。
- 网络需要能访问目标视频平台；完整便携包自带组件，开发用小包首次准备组件时需要访问官方站点。小鹅通/视频号/抖音及 B 站网页备用路径还需要已安装的 Microsoft Edge。代理设置不会跨电脑复制。
- 默认使用系统下载目录，视频和音频自动合并，通常为 MP4，部分格式为 MKV。
- 不自动读取浏览器 Cookie。部分需要登录、受地区限制或 DRM 保护的视频可能无法下载。
- 不声称所有网站均已支持；其他网站按实际验证逐项增加。

已在 Windows 上验证启动、组件初始化、换目录运行和 YouTube 画质解析；本机实际下载并合并过小鹅通回放、视频号、抖音和 B 站视频，连续下载与退出流程也已验证。具体解码、回归与云端验证记录见 [项目状态](docs/PROJECT_STATUS.md)。用户已反馈笔记本上的当前课程抓取和下载版本可用。macOS、Linux、ARM64 不支持。

## 在另一台电脑继续开发

AI 先读取根目录 [AGENTS.md](AGENTS.md)，再按 [开发环境与跨电脑接手](docs/DEVELOPMENT.md) 准备 Git、克隆源码并运行开发入口。完整说明包含必需/可选工具、依赖锁定、网络/登录配置、代码结构、构建验证和 GitHub 发布流程；[项目状态](docs/PROJECT_STATUS.md)记录已完成能力与待办。

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/setup-dev.ps1
```

也可双击 **准备开发环境.cmd**。入口检查基础条件、构建程序与 ZIP，自动下载缺少的官方视频组件并验证。源码仓库不保存登录凭证；新电脑向 GitHub 推送时需在浏览器正常授权。

## 源码与构建

源码入口在 `source/Launcher.cs`，下载流程在 `download.ps1`，组件初始化在 `bootstrap.ps1`。版本和 SHA-256 固定在 `dependencies.json`。

Windows 自带 .NET Framework 编译器即可构建：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/build.ps1 -Package -FullPackage
```

生成的便携 ZIP 位于 `dist`。开发用小包构建不需要预先安装下载组件；完整包构建前须运行开发准备入口。完整发布包附带下载组件及第三方许可；开发用小包缺少组件时会自动获取并校验。

```powershell
.\猛人下载器.exe --check
```

这会准备缺少的组件、检查它们能否启动，并显示系统下载位置。
