## v0.9.1（2026-11-04，修复自动更新经代理下载）

v0.9.0 发布后，用模拟旧版本（0.8.9 预览版）实测从 GitHub 自动更新到 v0.9.0 时下载失败（ECONNRESET）。curl 经同一代理 1MB 只需 0.5–1 秒，排查发现：更新模块自己接管“经代理连接”后，Node 不再知道默认端口，请求头写成 Host: github.com:80，GitHub 不停 301 跳回同一地址，于是退回直连（国内直连很慢，之前下 0.8.0 约 140KB/s，这次被断开）。修复：经代理时指定默认端口 443；下载断线或 60 秒没动静时自动重试最多 5 次，每次从断开处续传，最后整包核对 SHA-256。新增 1 项回归断言（经代理的连接设置带 443）。实测：经代理下载 v0.9.0 完整包 85MB 用时 22 秒并校验通过。发布 v0.9.1 后做完整自动更新：把 v0.9.1 完整包解压到含中文和空格的临时目录，版本改为 0.9.0 预览版，并在软件目录放一个用户文件；它从 GitHub 查到 v0.9.1，经代理 9 秒下完并校验，点安装后退出、apply-update.ps1 覆盖文件并以 v0.9.1 重新打开，日志“上次安装 v0.9.1：成功”，用户文件仍在，Updates 目录清空。v0.9.0 不撤回：它经代理失败后会退回直连，较慢但能续传，最终也能更新到本版。另：relay.mjs 的 X 媒体代理连接有同样的 Host 写法，X 的视频服务器目前接受，v0.7.0 实测可下，本版未改动，后续修改时一并验证。
