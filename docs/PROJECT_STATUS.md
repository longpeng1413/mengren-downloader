## 接手时应知道

当前用户正式开发目录是 `D:\猛人下载器`，但程序不依赖此路径；其他电脑可克隆到自己的可写目录。已与剪藏软件拆开，不调用其目录或配置。

公开 Release 的小 ZIP 首次启动下载约 194 MiB 官方组件。个人完整便携包在本机 `dist` 内，不公开上传。登录凭证、代理设置、Git 提交身份不会随仓库自动复制；需要在新电脑按开发文档分别配置。

如果刚克隆看不到根目录 EXE，这是正常的：它是构建产物、被 Git 忽略。运行 `scripts/setup-dev.ps1` 即可构建并准备运行组件。每次接手先读根目录 `AGENTS.md`。
