## 接手时应知道

当前用户正式开发目录是 `D:\猛人下载器`，但程序不依赖此路径；其他电脑可克隆到自己的可写目录。已与剪藏软件拆开，不调用其目录或配置。

公开 Release 的小 ZIP 首次启动下载约 194 MiB 官方组件。个人完整便携包在本机 `dist` 内，不公开上传。登录凭证、代理设置、Git 提交身份不会随仓库自动复制；需要在新电脑按开发文档分别配置。

如果刚克隆看不到根目录 EXE，这是正常的：它是构建产物、被 Git 忽略。运行 `scripts/setup-dev.ps1` 即可构建并准备运行组件。每次接手先读根目录 `AGENTS.md`。

## v0.3.0 试用版：连续下载、抖音与 B 站

- 正式 EXE 在同一个终端连续接受新链接；完成或失败后可继续，空回车结束。每个新任务重新选择画质，命令行单次调用与 --check 保持原语义。
- 抖音支持完整视频链接、短链及分享文案提取；通过正常专用 Edge 网页读取所选播放器，不导出 Cookie、不调用第三方解析服务。匿名 yt-dlp 在本机遇到 403/需要新 Cookie 提示，因此采用普通播放器路径；这不意味着所有视频均能下载。
- B 站支持 BV/AV、手机网页、b23.tv 和单个分 P；优先直接解析，失败时读取正常浏览器当前视频页/同站接口并合并音画。画质按上限和账号可获取范围选择，网页备用路径没有可匹配画质时明确失败，不下载超过上限的视频。
- 2026-10-12 本机实际连续运行：同一个正式 EXE 进程完成 B 站 720P，再完成抖音，然后空回车退出，退出码 0。入口成功、失败后继续、首次空输入及 --check 测试通过；真实 PowerShell 输入提示另有回归，不仅使用模拟工作脚本。
- B 站公开视频 BV1vL411G7N7：直接解析最高可用 1920×1080；实测选择 720P 下载及合并，23,063,095 字节、1280×720、11:09.48，AV1 视频 + AAC 音轨，整段解码通过。网页备用路径同样实测 720P 分离音画下载及合并，HEVC + AAC，11:09.48，整段解码通过。
- 抖音公开视频 6961737553342991651：实际下载 3,676,610 字节、576×1024、19.74 秒，H.264 + AAC，整段解码通过。当前抖音入口读取网页画质，不提供分辨率档位。
- 14 项平台/会话回归、本机正式 EXE --check、源码构建与公开 ZIP 检查通过。公开视频来自 yt-dlp 官方回归样例；测试视频不包含在发布包中。最终云端结果以 Actions 为准。
- 未验证所有抖音/B 站内容、会员专享、全部分 P、长时间连续使用、另一台实体电脑或所有网站格式；浏览器登录过期时仍需原网站正常登录。保留 v0.2.0 发布与个人完整包供回滚，新版公开包不含浏览器会话或第三方 EXE。
