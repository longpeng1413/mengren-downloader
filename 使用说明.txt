猛人下载器 v0.4.0 正式版（Windows x64 便携版）

完整解压，双击“猛人下载器.exe”，粘贴视频链接。
完成或失败后可在同一个窗口输入下一个链接；不输入内容、直接回车就退出。每个任务单独选择画质。
YouTube、B 站：可选最高画质、1080P、720P、480P，按画质上限选择，不放大低清晰度。
小鹅通：目前主要支持已结束直播回放；在软件打开的专用 Edge 中正常登录店铺，访问密码自行在原页面输入；读取成功后自动下载。
微信视频号：粘贴 weixin.qq.com/sph/ 分享链接，在专用 Edge 的元宝原网站首次登录；仅提交此链接解析，不发送聊天消息，再读取腾讯官方视频并保存。
抖音：粘贴视频链接、v.douyin.com 短链或含链接的分享文案；读取专用 Edge 中当前视频的播放器，登录/验证请在原网站完成。
B 站：支持 BV/AV、手机网页和 b23.tv 短链，以及单个分 P；直接解析失败后自动尝试网页读取。最高画质仍受账号权限限制。
小鹅通/视频号/抖音：下载网站提供的原始画质，不承诺可切换分辨率。

完成的视频保存到当前用户系统“下载”文件夹。完整便携包已包含三个官方组件，解压后直接运行，不需要另下组件。
专用 Edge 登录通常可复用至会话过期，不继承日常 Edge 登录，也不把登录状态复制到另一台电脑。软件不导出 Cookie。
需要 Windows 10/11、Intel/AMD x64。浏览器读取路径需要已安装 Microsoft Edge；所有平台仍受网站当前行为、权限和网络限制。

“创建桌面快捷方式.cmd”：创建本机入口。
“检查软件.cmd”：检查入口/官方组件。
“准备开发环境.cmd”：供开发者检查条件、构建、准备组件。
AI 接手先读 AGENTS.md 和 docs/DEVELOPMENT.md；源码仓库包含全部开发交接说明。
源码：https://github.com/longpeng1413/mengren-downloader

新增“播放抓取”：在链接处输入“抓取”，确认提示后输入“开启”，去微信播放视频，再输入“列表”和编号下载。操作详情及恢复网络方法见“抓取使用说明.txt”。用户已在笔记本实际使用并确认当前版本可用；各网站和课程仍取决于账号权限及媒体格式。需要 .NET Framework 4.8。
